Cài Đặt IPA Lên iPhone Không Cần Jailbreak

Tương thích từ iOS 16.0 đến iOS 18.0+ trên các dòng iPhone 8 / X đến iPhone 16 Pro Max.

BƯỚC 1

Tải File IPA

Tải tệp AISmartFramingCamera.ipa bản Build 300 từ GitHub.

BƯỚC 2

Mở Sideloadly

Khởi chạy Sideloadly trên máy tính Windows hoặc Mac.

BƯỚC 3

Kết Nối USB

Cắm cáp iPhone và chọn Tin cậy máy tính này.

BƯỚC 4

Ký Chứng Chỉ

Kéo file IPA vào, nhập Apple ID và bấm nút Start.

BƯỚC 5

Tin Cậy Profile

Cài đặt > Cài đặt chung > Quản lý VPN > Bấm Tin cậy.

Cài Đặt Vĩnh Viễn Không Thu Hồi (iOS 14 - 17.0)

1. Tải file IPA trực tiếp bằng Safari trên iPhone.

2. Trong ứng dụng Tệp (Files), chọn Chia sẻ > Mở bằng TrollStore.

3. Bấm Install để cài đặt vĩnh viễn, không bao giờ bị giới hạn 7 ngày.

Ký Chứng Chỉ Không Dây Qua Wi-Fi

1. Tải file IPA về máy qua Safari.

2. Mở AltStore, chọn tab My Apps và bấm dấu + ở góc trên.

3. Chọn tệp AISmartFramingCamera.ipa để AltStore nạp tự động.
